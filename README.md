# NeuroChat AI 🚀

NeuroChat AI is a modern AI-powered chat application built using the MERN Stack and integrated with Groq AI for real-time intelligent conversations.

The platform provides a premium SaaS-style user experience with authentication, chat thread management, markdown rendering, syntax highlighting, dark/light themes, and responsive UI.

---

# ✨ Features

* 🔐 JWT Authentication
* 💬 Real-Time AI Conversations
* 🧠 Groq AI Integration
* 📝 Markdown Rendering
* 🎨 Syntax Highlighting
* 📋 Copy Response Button
* 📂 Chat Thread Management
* 🌙 Dark / Light Theme
* 👤 User Profile Dropdown
* 📱 Responsive Modern UI
* ⚡ Fast and Interactive Experience

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/NeuroChat-AI.git
```

---

# Backend Setup

```bash
cd Backend
npm install
```

Create `.env` file:

```env
MONGO_URL=your_mongodb_url
JWT_SECRET=your_secret_key
GROQ_API_KEY=your_groq_api_key
NODE_ENV=development
```

Run backend:

```bash
npm start
```

---

# Frontend Setup

```bash
cd Frontend
npm install
npm run dev
```
